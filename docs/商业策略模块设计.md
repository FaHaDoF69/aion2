# 商业策略模块设计

## 1. 策略架构总览

### 1.1 策略分层设计
```
┌─────────────────────────────────────────┐
│           策略决策层                      │  ← 策略选择、风险评估、执行决策
├─────────────────────────────────────────┤
│           策略执行层                      │  ← 具体策略实现、交易执行
├─────────────────────────────────────────┤
│           数据分析层                      │  ← 价格分析、趋势预测、市场洞察
├─────────────────────────────────────────┤
│           市场监控层                      │  ← 实时数据采集、价格监控
└─────────────────────────────────────────┘
```

### 1.2 核心策略类型
- **捡漏策略 (Snipe Strategy)**: 快速识别和购买异常低价物品
- **套利策略 (Arbitrage Strategy)**: 利用价格差异进行套利交易
- **趋势策略 (Trend Strategy)**: 基于价格趋势的中长期投资
- **事件策略 (Event Strategy)**: 基于游戏事件的投机交易

## 2. 价格监控与分析模块

### 2.1 实时价格监控器 (RealTimePriceMonitor)

```csharp
public interface IPriceMonitor
{
    Task StartMonitoring(List<string> itemNames);
    Task StopMonitoring();
    Task<List<PriceUpdate>> GetLatestPrices();
    event EventHandler<PriceChangedEventArgs> PriceChanged;
    event EventHandler<AbnormalPriceEventArgs> AbnormalPriceDetected;
}

public class RealTimePriceMonitor : IPriceMonitor
{
    private readonly IAuctionHouseNavigator _navigator;
    private readonly IPriceHistoryRepository _priceRepository;
    private readonly IAbnormalPriceDetector _abnormalDetector;
    private readonly ILogger<RealTimePriceMonitor> _logger;
    
    private CancellationTokenSource _cancellationTokenSource;
    private readonly Dictionary<string, PriceSnapshot> _lastKnownPrices;
    
    public event EventHandler<PriceChangedEventArgs> PriceChanged;
    public event EventHandler<AbnormalPriceEventArgs> AbnormalPriceDetected;
    
    public async Task StartMonitoring(List<string> itemNames)
    {
        _cancellationTokenSource = new CancellationTokenSource();
        var token = _cancellationTokenSource.Token;
        
        _logger.LogInformation("开始监控 {Count} 个物品的价格", itemNames.Count);
        
        // 启动监控循环
        _ = Task.Run(async () => await MonitoringLoop(itemNames, token), token);
    }
    
    private async Task MonitoringLoop(List<string> itemNames, CancellationToken cancellationToken)
    {
        while (!cancellationToken.IsCancellationRequested)
        {
            try
            {
                foreach (var itemName in itemNames)
                {
                    await MonitorSingleItem(itemName);
                    
                    // 随机延迟避免过于规律
                    var delay = _random.Next(2000, 5000);
                    await Task.Delay(delay, cancellationToken);
                }
                
                // 完整轮询后的休息时间
                await Task.Delay(TimeSpan.FromMinutes(1), cancellationToken);
            }
            catch (OperationCanceledException)
            {
                break;
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "价格监控循环出现异常");
                await Task.Delay(TimeSpan.FromSeconds(30), cancellationToken);
            }
        }
    }
    
    private async Task MonitorSingleItem(string itemName)
    {
        try
        {
            // 1. 搜索物品
            if (!await _navigator.SearchItem(itemName))
            {
                _logger.LogWarning("搜索物品失败: {ItemName}", itemName);
                return;
            }
            
            // 2. 获取当前页面的物品列表
            var currentItems = await _navigator.GetCurrentPageItems();
            var targetItems = currentItems.Where(i => i.Name.Contains(itemName)).ToList();
            
            if (!targetItems.Any())
            {
                _logger.LogDebug("未找到物品: {ItemName}", itemName);
                return;
            }
            
            // 3. 分析价格变化
            foreach (var item in targetItems)
            {
                await AnalyzePriceChange(item);
            }
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "监控单个物品失败: {ItemName}", itemName);
        }
    }
    
    private async Task AnalyzePriceChange(AuctionItem item)
    {
        var currentPrice = item.Price;
        var lastKnown = _lastKnownPrices.GetValueOrDefault(item.Name);
        
        // 更新价格记录
        var priceRecord = new PriceRecord
        {
            ItemName = item.Name,
            Price = currentPrice,
            Quantity = item.Quantity,
            Timestamp = DateTime.Now,
            SellerName = item.SellerName
        };
        
        await _priceRepository.InsertPriceRecord(priceRecord);
        
        // 检测价格变化
        if (lastKnown != null)
        {
            var priceChange = currentPrice - lastKnown.Price;
            var changePercent = (double)priceChange / (double)lastKnown.Price;
            
            if (Math.Abs(changePercent) > 0.05) // 5%以上变化
            {
                PriceChanged?.Invoke(this, new PriceChangedEventArgs
                {
                    ItemName = item.Name,
                    OldPrice = lastKnown.Price,
                    NewPrice = currentPrice,
                    ChangePercent = changePercent,
                    Timestamp = DateTime.Now
                });
            }
        }
        
        // 检测异常价格
        if (await _abnormalDetector.IsAbnormallyLow(item.Name, currentPrice))
        {
            var deviation = await _abnormalDetector.CalculatePriceDeviation(item.Name, currentPrice);
            
            AbnormalPriceDetected?.Invoke(this, new AbnormalPriceEventArgs
            {
                Item = item,
                Deviation = deviation,
                Timestamp = DateTime.Now
            });
        }
        
        // 更新最后已知价格
        _lastKnownPrices[item.Name] = new PriceSnapshot
        {
            Price = currentPrice,
            Timestamp = DateTime.Now
        };
    }
}
```

### 2.2 价格趋势分析器 (PriceTrendAnalyzer)

```csharp
public interface IPriceTrendAnalyzer
{
    Task<PriceTrend> AnalyzeTrend(string itemName, TimeSpan period);
    Task<decimal> PredictPrice(string itemName, TimeSpan futureTime);
    Task<List<PricePattern>> IdentifyPatterns(string itemName);
    Task<MarketSentiment> GetMarketSentiment(string itemName);
}

public class StatisticalPriceTrendAnalyzer : IPriceTrendAnalyzer
{
    private readonly IPriceHistoryRepository _priceRepository;
    
    public async Task<PriceTrend> AnalyzeTrend(string itemName, TimeSpan period)
    {
        var fromDate = DateTime.Now - period;
        var priceHistory = await _priceRepository.GetPriceHistory(itemName, fromDate, DateTime.Now);
        
        if (priceHistory.Count < 10)
        {
            return new PriceTrend { Direction = TrendDirection.Unknown, Confidence = 0 };
        }
        
        // 计算移动平均线
        var shortMA = CalculateMovingAverage(priceHistory.TakeLast(10).Select(p => p.Price));
        var longMA = CalculateMovingAverage(priceHistory.TakeLast(30).Select(p => p.Price));
        
        // 计算趋势方向
        var direction = shortMA > longMA ? TrendDirection.Upward : 
                       shortMA < longMA ? TrendDirection.Downward : TrendDirection.Sideways;
        
        // 计算趋势强度
        var priceChanges = CalculatePriceChanges(priceHistory);
        var volatility = CalculateVolatility(priceChanges);
        var confidence = CalculateTrendConfidence(priceChanges, volatility);
        
        return new PriceTrend
        {
            Direction = direction,
            Confidence = confidence,
            Volatility = volatility,
            ShortTermMA = shortMA,
            LongTermMA = longMA,
            SupportLevel = CalculateSupportLevel(priceHistory),
            ResistanceLevel = CalculateResistanceLevel(priceHistory)
        };
    }
    
    public async Task<decimal> PredictPrice(string itemName, TimeSpan futureTime)
    {
        var trend = await AnalyzeTrend(itemName, TimeSpan.FromDays(7));
        var recentPrices = await _priceRepository.GetRecentPrices(itemName, 50);
        
        if (!recentPrices.Any()) return 0;
        
        var currentPrice = recentPrices.First().Price;
        
        // 简单线性预测（实际应用中可使用更复杂的模型）
        var hourlyChangeRate = CalculateHourlyChangeRate(recentPrices);
        var futureHours = futureTime.TotalHours;
        
        var predictedChange = (decimal)(hourlyChangeRate * futureHours);
        var predictedPrice = currentPrice + predictedChange;
        
        // 应用趋势调整
        var trendAdjustment = trend.Direction switch
        {
            TrendDirection.Upward => predictedPrice * 0.02m * (decimal)trend.Confidence,
            TrendDirection.Downward => predictedPrice * -0.02m * (decimal)trend.Confidence,
            _ => 0
        };
        
        return Math.Max(0, predictedPrice + trendAdjustment);
    }
    
    private double CalculateHourlyChangeRate(List<PriceRecord> prices)
    {
        if (prices.Count < 2) return 0;
        
        var changes = new List<double>();
        for (int i = 1; i < prices.Count; i++)
        {
            var timeDiff = (prices[i-1].Timestamp - prices[i].Timestamp).TotalHours;
            if (timeDiff > 0)
            {
                var priceChange = (double)(prices[i-1].Price - prices[i].Price);
                changes.Add(priceChange / timeDiff);
            }
        }
        
        return changes.Any() ? changes.Average() : 0;
    }
}
```

## 3. 交易策略实现

### 3.1 捡漏策略 (SnipeStrategy)

```csharp
public class SnipeStrategy : ITradingStrategy
{
    private readonly IAbnormalPriceDetector _priceDetector;
    private readonly IProfitabilityCalculator _profitCalculator;
    private readonly IRiskManager _riskManager;
    private readonly ITransactionExecutor _transactionExecutor;
    
    public string StrategyName => "Snipe";
    public StrategyType Type => StrategyType.ShortTerm;
    
    public async Task<List<TradingOpportunity>> FindOpportunities()
    {
        var opportunities = new List<TradingOpportunity>();
        
        // 获取当前拍卖行物品
        var currentItems = await _navigator.GetCurrentPageItems();
        
        foreach (var item in currentItems)
        {
            // 检查是否为异常低价
            if (await _priceDetector.IsAbnormallyLow(item.Name, item.Price))
            {
                // 计算预期利润
                var expectedProfit = await _profitCalculator.CalculateExpectedProfit(
                    item.Name, item.Price, item.Quantity);
                
                // 风险评估
                var riskAssessment = await _riskManager.AssessTransactionRisk(
                    item.Name, item.Price, item.Quantity);
                
                if (expectedProfit > 0 && riskAssessment.IsAcceptable)
                {
                    opportunities.Add(new TradingOpportunity
                    {
                        StrategyName = StrategyName,
                        Item = item,
                        ExpectedProfit = expectedProfit,
                        RiskLevel = riskAssessment.Level,
                        Confidence = await _priceDetector.CalculatePriceDeviation(item.Name, item.Price),
                        TimeWindow = TimeSpan.FromMinutes(5), // 捡漏需要快速执行
                        Priority = CalculatePriority(expectedProfit, riskAssessment.Level)
                    });
                }
            }
        }
        
        return opportunities.OrderByDescending(o => o.Priority).ToList();
    }
    
    public async Task<ExecutionResult> ExecuteStrategy(TradingOpportunity opportunity)
    {
        var startTime = DateTime.Now;
        
        try
        {
            // 1. 最后一次价格确认
            var currentItems = await _navigator.GetCurrentPageItems();
            var targetItem = currentItems.FirstOrDefault(i => 
                i.Name == opportunity.Item.Name && 
                i.Price == opportunity.Item.Price &&
                i.SellerName == opportunity.Item.SellerName);
            
            if (targetItem == null)
            {
                return ExecutionResult.Failed("目标物品已不存在或价格已变化");
            }
            
            // 2. 执行购买
            var purchaseResult = await _transactionExecutor.ExecutePurchase(targetItem);
            
            if (purchaseResult.IsSuccess)
            {
                // 3. 记录交易
                await RecordTransaction(targetItem, opportunity, startTime);
                
                return ExecutionResult.Success(purchaseResult.TransactionId);
            }
            else
            {
                return ExecutionResult.Failed(purchaseResult.ErrorMessage);
            }
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "执行捡漏策略失败: {ItemName}", opportunity.Item.Name);
            return ExecutionResult.Failed($"执行异常: {ex.Message}");
        }
    }
    
    private int CalculatePriority(decimal expectedProfit, RiskLevel riskLevel)
    {
        var basePriority = (int)(expectedProfit / 1000); // 每1000金币1分
        
        var riskPenalty = riskLevel switch
        {
            RiskLevel.Low => 0,
            RiskLevel.Medium => -10,
            RiskLevel.High => -30,
            _ => -50
        };
        
        return Math.Max(0, basePriority + riskPenalty);
    }
}
```

### 3.2 套利策略 (ArbitrageStrategy)

```csharp
public class CrossItemArbitrageStrategy : ITradingStrategy
{
    private readonly IPriceHistoryRepository _priceRepository;
    private readonly IItemRelationshipAnalyzer _relationshipAnalyzer;
    
    public string StrategyName => "CrossItemArbitrage";
    
    public async Task<List<TradingOpportunity>> FindOpportunities()
    {
        var opportunities = new List<TradingOpportunity>();
        
        // 获取相关物品组合
        var itemRelationships = await _relationshipAnalyzer.GetItemRelationships();
        
        foreach (var relationship in itemRelationships)
        {
            var opportunity = await AnalyzeRelationshipOpportunity(relationship);
            if (opportunity != null)
            {
                opportunities.Add(opportunity);
            }
        }
        
        return opportunities;
    }
    
    private async Task<TradingOpportunity> AnalyzeRelationshipOpportunity(ItemRelationship relationship)
    {
        // 例：分析材料与成品的价格关系
        if (relationship.Type == RelationshipType.MaterialToProduct)
        {
            return await AnalyzeMaterialArbitrage(relationship);
        }
        
        // 例：分析不同品质同类物品的价格关系
        if (relationship.Type == RelationshipType.QualityVariant)
        {
            return await AnalyzeQualityArbitrage(relationship);
        }
        
        return null;
    }
    
    private async Task<TradingOpportunity> AnalyzeMaterialArbitrage(ItemRelationship relationship)
    {
        var materialPrice = await GetCurrentPrice(relationship.SourceItem);
        var productPrice = await GetCurrentPrice(relationship.TargetItem);
        
        if (materialPrice == 0 || productPrice == 0) return null;
        
        // 计算制作成本
        var craftingCost = materialPrice * relationship.Ratio + relationship.AdditionalCost;
        
        // 计算利润率
        var profitMargin = (productPrice - craftingCost) / craftingCost;
        
        if (profitMargin > 0.15) // 15%以上利润率
        {
            return new TradingOpportunity
            {
                StrategyName = StrategyName,
                Item = new AuctionItem { Name = relationship.SourceItem, Price = materialPrice },
                ExpectedProfit = productPrice - craftingCost,
                TimeWindow = TimeSpan.FromHours(2), // 套利需要更多时间
                AdditionalData = new Dictionary<string, object>
                {
                    ["TargetItem"] = relationship.TargetItem,
                    ["CraftingRatio"] = relationship.Ratio,
                    ["ProfitMargin"] = profitMargin
                }
            };
        }
        
        return null;
    }
}
```

### 3.3 趋势策略 (TrendStrategy)

```csharp
public class TrendFollowingStrategy : ITradingStrategy
{
    private readonly IPriceTrendAnalyzer _trendAnalyzer;
    private readonly IMarketEventMonitor _eventMonitor;
    
    public string StrategyName => "TrendFollowing";
    
    public async Task<List<TradingOpportunity>> FindOpportunities()
    {
        var opportunities = new List<TradingOpportunity>();
        var monitoredItems = await GetTrendMonitoredItems();
        
        foreach (var itemName in monitoredItems)
        {
            var trend = await _trendAnalyzer.AnalyzeTrend(itemName, TimeSpan.FromDays(7));
            
            if (ShouldEnterPosition(trend))
            {
                var opportunity = await CreateTrendOpportunity(itemName, trend);
                if (opportunity != null)
                {
                    opportunities.Add(opportunity);
                }
            }
        }
        
        return opportunities;
    }
    
    private bool ShouldEnterPosition(PriceTrend trend)
    {
        // 强上升趋势且置信度高
        if (trend.Direction == TrendDirection.Upward && trend.Confidence > 0.7)
        {
            return true;
        }
        
        // 即将反转的下降趋势
        if (trend.Direction == TrendDirection.Downward && 
            trend.Confidence > 0.6 && 
            IsNearSupportLevel(trend))
        {
            return true;
        }
        
        return false;
    }
    
    private async Task<TradingOpportunity> CreateTrendOpportunity(string itemName, PriceTrend trend)
    {
        var currentPrice = await GetCurrentPrice(itemName);
        var predictedPrice = await _trendAnalyzer.PredictPrice(itemName, TimeSpan.FromDays(1));
        
        var expectedProfit = predictedPrice - currentPrice;
        
        if (expectedProfit > currentPrice * 0.05m) // 至少5%收益
        {
            return new TradingOpportunity
            {
                StrategyName = StrategyName,
                Item = new AuctionItem { Name = itemName, Price = currentPrice },
                ExpectedProfit = expectedProfit,
                TimeWindow = TimeSpan.FromDays(1),
                Confidence = trend.Confidence,
                AdditionalData = new Dictionary<string, object>
                {
                    ["PredictedPrice"] = predictedPrice,
                    ["TrendDirection"] = trend.Direction,
                    ["StopLoss"] = trend.SupportLevel
                }
            };
        }
        
        return null;
    }
}
```

### 4.1 投资组合风险管理器 (PortfolioRiskManager)

```csharp
public interface IPortfolioRiskManager
{
    Task<bool> IsWithinRiskLimits(string itemName, decimal price, int quantity);
    Task<decimal> GetMaxInvestmentAmount(string itemName);
    Task<PortfolioRisk> AssessPortfolioRisk();
    Task RebalancePortfolio();
}

public class PortfolioRiskManager : IPortfolioRiskManager
{
    private readonly ITransactionRepository _transactionRepository;
    private readonly IConfiguration _config;
    
    public async Task<bool> IsWithinRiskLimits(string itemName, decimal price, int quantity)
    {
        var totalInvestment = price * quantity;
        
        // 1. 单笔投资限额检查
        var maxSingleInvestment = _config.GetValue<decimal>("Risk:MaxSingleInvestment");
        if (totalInvestment > maxSingleInvestment)
        {
            return false;
        }
        
        // 2. 单物品总投资限额检查
        var currentInvestment = await GetCurrentInvestment(itemName);
        var maxItemInvestment = await GetMaxInvestmentAmount(itemName);
        if (currentInvestment + totalInvestment > maxItemInvestment)
        {
            return false;
        }
        
        // 3. 总资金使用率检查
        var totalPortfolioValue = await GetTotalPortfolioValue();
        var maxPortfolioUsage = _config.GetValue<decimal>("Risk:MaxPortfolioUsage");
        var currentUsage = await GetCurrentPortfolioUsage();
        
        if ((currentUsage + totalInvestment) / totalPortfolioValue > maxPortfolioUsage)
        {
            return false;
        }
        
        return true;
    }
    
    public async Task<PortfolioRisk> AssessPortfolioRisk()
    {
        var holdings = await GetCurrentHoldings();
        var totalValue = holdings.Sum(h => h.CurrentValue);
        
        // 计算集中度风险
        var concentrationRisk = CalculateConcentrationRisk(holdings);
        
        // 计算流动性风险
        var liquidityRisk = await CalculateLiquidityRisk(holdings);
        
        // 计算市场风险
        var marketRisk = await CalculateMarketRisk(holdings);
        
        return new PortfolioRisk
        {
            TotalValue = totalValue,
            ConcentrationRisk = concentrationRisk,
            LiquidityRisk = liquidityRisk,
            MarketRisk = marketRisk,
            OverallRisk = CalculateOverallRisk(concentrationRisk, liquidityRisk, marketRisk)
        };
    }
    
    private double CalculateConcentrationRisk(List<Holding> holdings)
    {
        if (!holdings.Any()) return 0;
        
        var totalValue = holdings.Sum(h => h.CurrentValue);
        var weights = holdings.Select(h => (double)(h.CurrentValue / totalValue)).ToList();
        
        // 使用赫芬达尔指数计算集中度
        var herfindahlIndex = weights.Sum(w => w * w);
        
        // 转换为风险分数 (0-1)
        return Math.Min(1.0, herfindahlIndex * 2);
    }
}
```

### 4.2 动态止损管理器 (DynamicStopLossManager)

```csharp
public interface IStopLossManager
{
    Task SetStopLoss(string itemName, decimal stopLossPrice, StopLossType type);
    Task UpdateStopLoss(string itemName, decimal newPrice);
    Task<List<StopLossOrder>> CheckStopLossOrders();
    Task ExecuteStopLoss(StopLossOrder order);
}

public class DynamicStopLossManager : IStopLossManager
{
    private readonly Dictionary<string, StopLossOrder> _stopLossOrders;
    private readonly IPriceTrendAnalyzer _trendAnalyzer;
    
    public async Task SetStopLoss(string itemName, decimal stopLossPrice, StopLossType type)
    {
        var order = new StopLossOrder
        {
            ItemName = itemName,
            StopLossPrice = stopLossPrice,
            Type = type,
            CreatedAt = DateTime.Now,
            IsActive = true
        };
        
        _stopLossOrders[itemName] = order;
        
        _logger.LogInformation("设置止损: {ItemName} @ {Price} ({Type})", 
            itemName, stopLossPrice, type);
    }
    
    public async Task UpdateStopLoss(string itemName, decimal newPrice)
    {
        if (!_stopLossOrders.ContainsKey(itemName)) return;
        
        var order = _stopLossOrders[itemName];
        
        if (order.Type == StopLossType.Trailing)
        {
            // 追踪止损：只在有利方向调整
            var currentPrice = await GetCurrentPrice(itemName);
            var profitMargin = (currentPrice - order.OriginalPrice) / order.OriginalPrice;
            
            if (profitMargin > 0.1m) // 盈利超过10%时启用追踪
            {
                var newStopLoss = currentPrice * 0.95m; // 保留5%利润
                if (newStopLoss > order.StopLossPrice)
                {
                    order.StopLossPrice = newStopLoss;
                    _logger.LogInformation("更新追踪止损: {ItemName} @ {Price}", itemName, newStopLoss);
                }
            }
        }
    }
    
    public async Task<List<StopLossOrder>> CheckStopLossOrders()
    {
        var triggeredOrders = new List<StopLossOrder>();
        
        foreach (var order in _stopLossOrders.Values.Where(o => o.IsActive))
        {
            var currentPrice = await GetCurrentPrice(order.ItemName);
            
            if (ShouldTriggerStopLoss(order, currentPrice))
            {
                triggeredOrders.Add(order);
            }
        }
        
        return triggeredOrders;
    }
    
    private bool ShouldTriggerStopLoss(StopLossOrder order, decimal currentPrice)
    {
        return order.Type switch
        {
            StopLossType.Fixed => currentPrice <= order.StopLossPrice,
            StopLossType.Trailing => currentPrice <= order.StopLossPrice,
            StopLossType.Percentage => currentPrice <= order.OriginalPrice * (1 - order.PercentageThreshold),
            _ => false
        };
    }
}
```

这个商业策略模块设计包含了：

1. **价格监控分析**: 实时价格监控、趋势分析、价格预测
2. **多种交易策略**: 捡漏策略、套利策略、趋势策略
3. **风险管理**: 投资组合管理、动态止损、风险评估
4. **智能决策**: 机会识别、优先级排序、执行优化

每个策略都考虑了实际的市场情况和风险控制，确保系统能够稳定盈利并控制风险。
