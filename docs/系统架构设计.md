# Aion 2 拍卖行智能辅助系统 - 系统架构设计

## 1. 整体架构概览

```
┌─────────────────────────────────────────────────────────────┐
│                    用户配置层 (Configuration Layer)              │
├─────────────────────────────────────────────────────────────┤
│                    业务逻辑层 (Business Logic Layer)            │
├─────────────────────────────────────────────────────────────┤
│                    游戏交互层 (Game Interaction Layer)          │
├─────────────────────────────────────────────────────────────┤
│                    基础功能层 (Foundation Layer)                │
└─────────────────────────────────────────────────────────────┘
```

## 2. 各层详细设计

### 2.1 用户配置层 (Configuration Layer)

**职责**: 管理所有用户配置、策略参数和系统设置

#### 核心模块:
- **ConfigurationManager** - 配置文件管理器
- **StrategyParameterManager** - 交易策略参数管理
- **UserPreferencesManager** - 用户偏好设置
- **TemplateManager** - 图像模板管理

#### 配置文件结构:
```json
{
  "gameSettings": {
    "windowTitle": "Aion2",
    "gameRegion": "TW/KR",
    "resolution": "1920x1080"
  },
  "tradingStrategy": {
    "maxInvestmentPerItem": 1000000,
    "priceThreshold": 0.7,
    "operationInterval": [3000, 8000],
    "emergencyStopLoss": 0.3
  },
  "safetySettings": {
    "randomDelayRange": [500, 2000],
    "maxOperationsPerHour": 50,
    "humanBehaviorEnabled": true
  }
}
```

### 2.2 业务逻辑层 (Business Logic Layer)

**职责**: 实现核心业务逻辑和交易策略

#### 核心模块:

##### 2.2.1 价格监控模块 (PriceMonitoringModule)
- **PriceScanner** - 价格扫描器
- **PriceAnalyzer** - 价格分析器
- **TrendPredictor** - 趋势预测器
- **AlertManager** - 价格预警管理

##### 2.2.2 交易策略模块 (TradingStrategyModule)
- **ArbitrageStrategy** - 套利策略
- **SnipeStrategy** - 捡漏策略
- **TimeBasedStrategy** - 时间套利策略
- **RiskManager** - 风险管理器

##### 2.2.3 数据分析模块 (DataAnalysisModule)
- **HistoricalDataAnalyzer** - 历史数据分析
- **MarketTrendAnalyzer** - 市场趋势分析
- **ProfitabilityCalculator** - 盈利能力计算
- **ReportGenerator** - 报告生成器

### 2.3 游戏交互层 (Game Interaction Layer)

**职责**: 处理与Aion2游戏的所有交互操作

#### 核心模块:

##### 2.3.1 UI识别模块 (UIRecognitionModule)
- **WindowManager** - 游戏窗口管理
- **AuctionHouseDetector** - 拍卖行界面检测
- **ItemListParser** - 物品列表解析器
- **PriceExtractor** - 价格信息提取器

##### 2.3.2 操作执行模块 (OperationExecutionModule)
- **MouseController** - 鼠标控制器
- **KeyboardController** - 键盘控制器
- **NavigationController** - 界面导航控制
- **TransactionExecutor** - 交易执行器

##### 2.3.3 状态监控模块 (StateMonitoringModule)
- **GameStateMonitor** - 游戏状态监控
- **ConnectionMonitor** - 网络连接监控
- **ErrorDetector** - 错误检测器
- **RecoveryManager** - 异常恢复管理

### 2.4 基础功能层 (Foundation Layer)

**职责**: 提供底层技术支持和基础服务

#### 核心模块:

##### 2.4.1 图像处理模块 (ImageProcessingModule)
- **ScreenCapture** - 屏幕截图
- **ImageMatcher** - 图像匹配
- **OCREngine** - 文字识别
- **TemplateProcessor** - 模板处理器

##### 2.4.2 数据存储模块 (DataStorageModule)
- **DatabaseManager** - 数据库管理
- **PriceHistoryRepository** - 价格历史仓储
- **TransactionRepository** - 交易记录仓储
- **CacheManager** - 缓存管理

##### 2.4.3 系统服务模块 (SystemServiceModule)
- **LoggingService** - 日志服务
- **SecurityService** - 安全服务
- **NotificationService** - 通知服务
- **SchedulerService** - 任务调度服务

## 3. 模块间通信机制

### 3.1 事件驱动架构
```csharp
// 事件总线设计
public interface IEventBus
{
    void Publish<T>(T eventData) where T : IEvent;
    void Subscribe<T>(Action<T> handler) where T : IEvent;
}

// 核心事件类型
public class PriceUpdatedEvent : IEvent
{
    public string ItemName { get; set; }
    public decimal NewPrice { get; set; }
    public DateTime Timestamp { get; set; }
}

public class AbnormalPriceDetectedEvent : IEvent
{
    public string ItemName { get; set; }
    public decimal CurrentPrice { get; set; }
    public decimal ExpectedPrice { get; set; }
    public double Deviation { get; set; }
}
```

### 3.2 依赖注入容器
```csharp
// 服务注册
services.AddSingleton<IConfigurationManager, ConfigurationManager>();
services.AddScoped<IPriceScanner, PriceScanner>();
services.AddScoped<IArbitrageStrategy, ArbitrageStrategy>();
services.AddScoped<IMouseController, MouseController>();
services.AddScoped<IScreenCapture, ScreenCapture>();
```

## 4. 安全与防检测设计

### 4.1 人性化操作模拟
- **随机延迟**: 基础延迟 + 高斯分布随机偏移
- **鼠标轨迹**: 贝塞尔曲线模拟真实移动路径
- **操作节奏**: 模拟人类思考和反应时间
- **行为变化**: 定期调整操作模式避免模式识别

### 4.2 风险控制机制
- **操作频率限制**: 智能调节操作间隔
- **资金管理**: 分散投资降低单笔风险
- **异常检测**: 监控系统状态和游戏响应
- **紧急停止**: 检测到异常时立即停止操作

## 5. 性能优化策略

### 5.1 图像处理优化
- **ROI区域**: 只处理关键区域减少计算量
- **多线程**: 并行处理多个识别任务
- **缓存机制**: 缓存常用模板和识别结果
- **算法优化**: 使用高效的图像匹配算法

### 5.2 数据处理优化
- **批量操作**: 批量插入和更新数据库
- **索引优化**: 为查询字段建立合适索引
- **内存管理**: 及时释放不需要的资源
- **异步处理**: 使用异步I/O提高响应性能
