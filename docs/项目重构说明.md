# Aion2 项目重构说明

## 📋 重构概述

本项目已成功重构为多项目解决方案架构，包含：
- **Aion2Helper.Core**: 共享类库项目
- **Aion2Helper.Client**: 用户端WinForms应用
- **Aion2Helper.Admin**: 管理端WinForms应用

## 📦 各项目职责

### Aion2Helper.Client (用户端)
- 游戏窗口检测和监控
- 图像识别和OCR
- 自动购买功能
- 监控物品管理
- 价格趋势分析

### Aion2Helper.Admin (管理端)
- 跨机器数据查看
- 监控物品管理（所有机器）
- 购买记录查询和统计
- 数据统计和分析
- 系统管理功能

### Aion2Helper.Core (共享库)
- 数据模型（Models）
- 数据库访问（Data）
- 业务服务（Services）
- 工具类（Utils）
- 配置管理（Config）

## 🚀 如何运行

### 运行用户端
```bash
dotnet run --project Aion2Helper.Client/Aion2Helper.Client.csproj
```

### 运行管理端
```bash
dotnet run --project Aion2Helper.Admin/Aion2Helper.Admin.csproj
```

### 编译所有项目
```bash
dotnet build aion2.sln
```

## 📊 管理端功能

### 1. 监控物品管理
- 查看所有机器的监控物品
- 按物品名称搜索
- 删除监控物品
- 查看物品的监控配置（目标价格、优先级、是否启用等）

### 2. 购买记录管理
- 按日期范围查看购买记录
- 按机器码筛选
- 查看详细的购买信息（物品、数量、价格、状态等）

### 3. 统计分析
- 显示活跃机器总数（最近30天）
- 显示总购买次数（已完成的交易）
- 显示总利润统计

## ⚠️ 注意事项

1. **数据库配置**: 所有项目共享同一个数据库配置（在Core项目中）
2. **机器码**: 每个项目都使用相同的机器码生成逻辑
3. **日志记录**: 使用Core项目中的Logger类进行统一日志记录
4. **编译警告**: CA1416警告是正常的，因为这是Windows专用的应用程序
