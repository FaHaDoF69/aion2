# 项目结构设计

```

├── src/                                    # 源代码目录
│   ├── Aion2.AuctionHelper.Core/          # 核心业务逻辑
```

这个项目结构设计采用了：

1. **分层架构**: 清晰的领域驱动设计分层
2. **模块化**: 每个功能模块独立，便于维护和测试
3. **可扩展性**: 接口驱动设计，便于功能扩展
4. **配置管理**: 完善的配置文件组织
5. **工具支持**: 丰富的开发和维护工具

这样的结构能够支持大型项目的开发和维护需求。
