# Aion 2 拍卖行智能辅助系统

## 📋 项目简介

这是一个基于图像识别技术的Aion 2拍卖行智能辅助工具，采用WPF界面，提供实时价格监控、异常价格检测、智能交易策略等功能。

## ✨ 主要特性

- **🎯 实时监控**: 自动扫描拍卖行物品价格
- **⚡ 异常检测**: 智能识别异常低价物品
- **🤖 自动交易**: 支持多种交易策略
- **🛡️ 安全防护**: 人性化操作模拟，降低检测风险
- **📊 数据分析**: 价格历史记录和趋势分析
- **🎨 现代界面**: 美观的WPF用户界面

## 🚀 快速开始

### 环境要求
- Windows 10/11 (64位)
- .NET 8.0 运行时
- 至少 4GB 内存

### 运行项目
```bash
cd Aion2AuctionHelper/Aion2AuctionHelper
dotnet run
```

## 📁 项目结构

```
Aion2AuctionHelper/
├── Models/              # 数据模型
├── Services/            # 服务类
├── Forms/               # 窗体
├── templates/           # 图像模板
├── detected_items/      # 检测到的物品
├── records/            # 记录文件
└── appsettings.json    # 配置文件
```

## 🛠️ 技术栈

- **C# .NET 8**: 核心开发语言
- **WPF**: 用户界面框架
- **OpenCV**: 图像处理和识别
- **System.Drawing**: 屏幕截图和图像操作
